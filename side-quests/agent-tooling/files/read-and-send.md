# Reading permission and sending permission

Reconstructed brief · 2026-10-24

A reconstructed policy statement. Accounts, contacts, pairing data and runtime settings are excluded.

---

## Interaction policy

Reading incoming messages must not trigger an outgoing response.

Sending a message requires an explicit instruction from the user. Permission to observe a channel is not permission to participate in it.

A mode that disables both reading and sending does not meet this requirement. The working material establishes the desired behaviour, not an implemented permission gate.

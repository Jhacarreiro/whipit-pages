The Roads Not Taken

Current research focus

What if an AI-assisted development run could show the important decisions behind one solution, the context-dependent alternatives we did not take, and eventually let us explore a different path?

Decision Multiverse aims to map consequential choices without preset branch counts or categories. First we will test whether we can capture decisions faithfully, distinguish evidence from inference, and present a useful visual map. Later we hope to replay selected alternatives in isolation and compare real solution quality, cost and human intervention. Unexecuted paths are hypotheses, never observed results.

Core question: does exploring alternative decisions deliver better solutions than following one path with the same total resources?
